EX.NO:3 Exploring the different types of prompts- Straightforward Prompts - Tabular Format Prompting - Missing Word Prompting - Preceding Question Prompting.

Aim: To write the prompts for the following prompt types for 2 different scenarios of Each type.

1.Straightforward Prompts

2.Tabular Format Prompting

3.Preceding Question Prompting

4.Missing Word Prompting

Explanation - Any one use case from Unit 5 or any 2 own use cases with the unit 2 Prompt type

Procedure:

Write 2 different prompts for different use cases, refer the following Examples

Example:

Straightforward Prompts:

• "Define photosynthesis in one sentence."

"List three advantages of electric vehicles."

Tabular Format Prompting:

• "Compare and contrast AC and DC current in a table."

• "Provide a table listing five programming languages, their paradigms, and one use case each."

Preceding Question Prompting:

• "Why is climate change a global concern? Explain how greenhouse gases contribute to global warming."

• "How do vaccines work? Describe the process of immunization in simple terms."

Missing Word Prompting:

• "The capital of France is ____."

• "In photosynthesis, plants absorb sunlight to produce ____."

OUTPUT:
1. Straightforward Prompts:

• “Explain the causes of global warming in simple terms.”
output: Global warming happens because too much heat is trapped in the Earth’s atmosphere. This is mainly caused by human activities that increase greenhouse gases like carbon dioxide and methane. Burning fossil fuels such as coal, petrol, and diesel for electricity, transport, and industries releases large amounts of carbon dioxide. Cutting down forests also worsens the problem because trees absorb carbon dioxide from the air. Pollution from factories, vehicles, and agriculture adds more harmful gases, causing the Earth’s temperature to rise gradually.

• “List four applications of Artificial Intelligence in healthcare.”
output: 1. AI helps doctors diagnose diseases quickly using medical images and test results.
2. AI-powered robots assist surgeons during complex surgeries with high precision.
3. Virtual health assistants provide patient support and reminders for medicines.
4. AI is used in drug discovery to develop new medicines faster and more accurately.


2. Tabular Format Prompting:

• “Compare Python, Java, and C++ in a table with columns for speed, platform, and applications.”
output: 
| Programming Language | Speed     | Platform             | Applications                          |
| -------------------- | --------- | -------------------- | ------------------------------------- |
| Python               | Moderate  | Cross-platform       | Data Science, AI, Web Development     |
| Java                 | Fast      | Cross-platform (JVM) | Enterprise Applications, Android Apps |
| C++                  | Very Fast | Cross-platform       | Game Development, System Software     |


• “Create a table showing different types of databases, their features, and applications.”
output:
| Type of Database         | Features                                    | Applications                                 |
| ------------------------ | ------------------------------------------- | -------------------------------------------- |
| Relational Database      | Stores data in tables with rows and columns | Banking systems, School management           |
| NoSQL Database           | Handles large and unstructured data         | Social media, Real-time analytics            |
| Hierarchical Database    | Organizes data in a tree-like structure     | File systems, Organization charts            |
| Distributed Database     | Data stored across multiple locations       | Cloud computing, Online services             |
| Object-Oriented Database | Stores data as objects                      | Multimedia systems, Engineering applications |


3.Preceding Question Prompting:

• “What is digital marketing? How does it help businesses grow?”
output: Digital marketing is the promotion of products and services using digital platforms such as websites, social media, search engines, email, and mobile apps. It helps businesses grow by reaching a larger audience, increasing brand awareness, attracting more customers, and improving sales. Digital marketing also allows companies to communicate directly with customers, analyze market trends, and advertise at lower costs compared to traditional marketing methods.

• “Why is water conservation important? Explain methods to save water.”
output: Water conservation is important because fresh water is limited and essential for drinking, farming, industries, and daily life. Saving water helps prevent shortages, protects the environment, and ensures enough water for future generations.

Methods to save water include repairing leaking taps and pipes, using water-efficient appliances, turning off taps when not in use, collecting rainwater through rainwater harvesting, reusing water for gardening, and avoiding unnecessary wastage of water in homes and industries.

4. Missing Word Prompting:

• “The largest planet in the solar system is ________.”
output: The largest planet in the solar system is **Jupiter**.

• “A network that connects computers worldwide is called the ________.”
output: A network that connects computers worldwide is called the **Internet**.

RESULT: Thus,the experiment for exploring different type of prompt is completed successfully.
